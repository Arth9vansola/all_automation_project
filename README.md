# Automation Exercise – End-to-End Test Automation

A Python-based web automation project using Selenium WebDriver and Pytest to validate key e-commerce workflows on [Automation Exercise](https://www.automationexercise.com/).

## Project Overview

This project contains **26 automated test cases** covering 5 major application workflows.

## Test Coverage

| Workflow | Coverage |
|---|---|
| User Registration | Registration and account-related scenarios |
| Login | Login functionality |
| Product Search | Product search and validation |
| Shopping Cart | Cart interactions and validation |
| Checkout | Checkout workflow validation |

## Tech Stack

- Python
- Selenium WebDriver
- Playwright
- Pytest
- XPath Locators

## Key Features

- Automated end-to-end UI testing.
- XPath-based element identification.
- Pytest assertions for expected-result validation.
- Test organization and reusable automation scripts.

## Prerequisites

- Python installed
- Google Chrome browser
- pip package manager

## Installation

Clone the repository:

```bash
git clone https://github.com/Arth9vansola/all_automation_project.git
```

Navigate into the project:

```bash
cd all_automation_project
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

## Execute Tests

Run the complete test suite:

```bash
pytest
```

Run tests with verbose output:

```bash
pytest -v
```

## Project Purpose

This project demonstrates practical skills in Python-based web automation, Selenium WebDriver, XPath locators, Pytest, and end-to-end testing.
